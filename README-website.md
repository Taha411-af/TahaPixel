این شاخه (add-website) شامل یک سایت سادهٔ استاتیک است.

چکار کردم:
- فایل index.html را گذاشتم و لینک‌های کانال روبیکا و آپارات شما را قرار دادم.
- فایل styles.css برای استایل ساده ساخته شد.
- فایل videos.json محل نگهداری لیست ویدیوها است. فرمت هر ویدیو:
  {
    "title": "عنوان ویدیو",
    "url": "لینک ویدیو (آپارات یا هر جا)",
    "thumbnail": "آدرس عکس کوچک یا لینک خارجی"
  }

چطور PR بسازیم:
- من فایل‌ها را در شاخه add-website گذاشتم.
- حالا باید یک Pull Request (درخواست تغییر) باز شود تا تو آن را بررسی و merge کنی.
  برای باز کردن PR: به صفحه گیت‌هاب مخزن برو، روی "Compare & pull request" برای شاخه add-website کلیک کن یا از منوی "Pull requests" یک PR جدید بساز و شاخهٔ مبدا را add-website انتخاب کن.

چطور بعداً ویدیو اضافه کنی (خیلی ساده):
1) برو به فایل videos.json در شاخهٔ اصلی یا شاخه‌ای که PR ایجاد می‌کنی.
2) روی Edit کلیک کن و یک آیتم جدید مثل نمونه اضافه کن.
3) Commit changes کن.

یا اگر می‌خواهی من اضافه کنم: هر بار لینک و تامنیل را بفرست؛ من یک commit و PR می‌سازم.

اگر می‌خواهی من خودم PR را هم باز کنم، بگو تا بررسی کنم آیا دسترسی لازم دارم؛ در غیر این صورت تو خیلی آسان می‌تونی از صفحهٔ گیت‌هاب PR را باز کنی.
